# LC glossary

- **LC** — Living Companion track (formerly "Phase 4"; LC-DEC-001).
- **Studigo** — the orange, wingless dragon companion.
- **Dock / floating host** — draggable companion overlay; position saved normalized.
- **Strip host** — fixed companion row between nav and rail (slot not yet built; LC-DEC-019).
- **Beat** — a short choreographed motion (e.g. hop, spin) that returns to a rest pose.
- **Expression** — face/body preset defined relative to neutral; blends ≤200 ms.
- **Motion director** — code that maps events + mood to beats/expressions.
- **Mood meter** — per-session, in-memory mood value (LC-DEC-006).
- **Stall** — learner inactivity event emitted only by the Guided Learn mission director.
- **GL08** — Guided Learn companion work item sharing the event list.
- **CompanionRenderer** — renderer interface; implementations `SpriteRenderer` (current WebP, fallback) and `RiveRenderer`.
- **MouthDriver** — plug-in feeding mouth shapes from amplitude, visemes, or word boundaries (LC-DEC-008).
- **Calm mode** — reduced-motion variant honoring prefers-reduced-motion.
- **Outfit** — cosmetic, school-subject themed skin (LC-DEC-009).
- **REA** — reverse-engineering/analysis tool used to extract Coucou behavior.
