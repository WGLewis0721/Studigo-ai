# Studigo brand

## Official visual reference

[Brand foundation](./STUDIGO_OFFICIAL_BRAND_BOARD.png) is the current visual source of truth for Studigo's identity. It reflects the live site, V2 design system, implemented CSS tokens, and public companion asset. The 2026-10-15 revision incorporates marked feedback: retain the palette, type, tactile surfaces, action language, and source evidence; avoid substitute character art and an invented app icon.

Use the [design system](../DESIGN_SYSTEM.md) for exact tokens, behavior, accessibility, responsive rules, and implementation guidance. The board contains illustrative component specimens, not pixel-perfect product screenshots.

## Guided learning application

[Guided learning brand application](./STUDIGO_GUIDED_LEARNING_BRAND_APPLICATION.png) shows proposed desktop and phone compositions for the planned learning journey. The screens are layout studies informed by the marked references and the guided learning UI plan. They are not shipped product screenshots. The orange and teal wordmark is an exploration, not an approved replacement logo. Source blocks intentionally use placeholders until an actual passage can be verified.

The canonical orange scholar assets remain in `docs/brand/mascot/` and `apps/web/public/mascot/`. New guided learning flows still require product design and acceptance work.
