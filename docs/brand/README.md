# Studigo brand

## Official visual reference

[Studigo Official Brand Board](./STUDIGO_OFFICIAL_BRAND_BOARD.png) is the approved visual source of truth for Studigo's current identity (approved 2026-10-14). It was built from the live production site, the V2 design system, the implemented CSS tokens, and the canonical public mascot assets.

Use the board for visual direction: wordmark treatment, color architecture, typography, mascot, tactile materials, component appearance, and source evidence. The [design system](../DESIGN_SYSTEM.md) provides the detailed token values, behavior, accessibility, responsive rules, and implementation guidance. When a proposed visual change conflicts with the approved board, update the board and design system together after review.

The board depicts component specimens, not a promised future screen or a pixel-perfect screenshot. Guided learning flows and new UI require their own design and acceptance work. Preserve the canonical orange scholar asset library in `docs/brand/mascot/` and `apps/web/public/mascot/`.
