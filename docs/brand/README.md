# Studigo brand

## Official visual reference

[Brand foundation](./STUDIGO_OFFICIAL_BRAND_BOARD.png) is the current visual source of truth for Studigo's identity. It reflects the live site, V2 design system, implemented CSS tokens, and public companion asset. The 2026-10-15 revision incorporates marked feedback: retain the palette, type, tactile surfaces, action language, and source evidence; avoid substitute character art and an invented app icon.

Use the [design system](../DESIGN_SYSTEM.md) for exact tokens, behavior, accessibility, responsive rules, and implementation guidance. The board contains illustrative component specimens, not pixel-perfect product screenshots. The dimensional shells, keys, and readouts are visual material studies, not manufactured hardware or shipped product assets. Their treatment follows the documented tactile material language; the exact token labels and canonical mascot asset are source-backed.

## Studigo V2 Phase 3 application

[Guided learning brand application](./STUDIGO_GUIDED_LEARNING_BRAND_APPLICATION.png) applies that visual language to the proposed Phase 3 UX redesign. Learn is a guided mission for unfamiliar material, Coach helps apply and recover, and Practice tests independent understanding. The board illustrates Mission start/resume, interactive lesson steps, Source Spotlight, contextual tap/speech/type actions, and phone composition. Learn checkpoints are ungraded; assisted actions do not earn official mastery. Speech requires transcription review, and a source passage appears only after verification.

This sheet is a layout study, not shipped product screenshots. The orange and teal wordmark is an exploration, not an approved replacement logo. Its content follows the Guided Learning Experience and UI/UX plans, which define GL01–GL10 and UX01–UX10 across four delivery waves. The UI examples are not evidence that those deliverables have shipped.

The canonical orange scholar assets remain in `docs/brand/mascot/` and `apps/web/public/mascot/`. Phase 3 product implementation and acceptance remain separate work.
