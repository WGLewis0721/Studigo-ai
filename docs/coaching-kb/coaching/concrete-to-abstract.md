# Concrete to abstract

## Current Studigo definition
Start with a concrete or visual model, connect it to the idea, and only then move to symbolic or abstract practice.

## Real-world paradigm
This maps directly to **Concrete-Representational-Abstract (CRA)** and the closely related **Concrete-Pictorial-Abstract (CPA)** sequence.

## Operational definition
Build meaning through manipulable or real objects, explicitly bridge that representation to a drawing/model, then connect both to mathematical symbols or formal notation.

## Coaching moves
Concrete model → representational/pictorial model → explain connection → abstract notation → reverse-map symbols back to representation when confusion appears.

## Best-fit use cases
Place value, fractions, ratios, operations, algebraic structure, geometry, word problems.

## Example
For 3 × 4, show three groups of four counters, then three drawn groups/bar segments, then `3 × 4 = 12`.

## Guardrails
The physical/visual stage must carry the same structure as the symbols. Decorative pictures are not CRA.
