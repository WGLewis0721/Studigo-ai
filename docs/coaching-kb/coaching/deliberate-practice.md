# Deliberate practice

## Current Studigo definition
Targeted reps that build automaticity: isolate one skill, vary difficulty gradually, give immediate specific feedback, and revisit errors.

## Real-world paradigm
**Deliberate practice** is goal-directed practice deliberately designed to improve a specific aspect of performance, with focused attention, informative feedback, repetition, and error correction.

## Operational definition
Select a weakness small enough to practice directly, set a clear performance target, provide attempts near the learner's current level, deliver actionable feedback, and repeat with adjustment.

## Coaching moves
Diagnose → isolate → attempt → feedback → corrected attempt → slight variation/difficulty increase.

## Best-fit use cases
Arithmetic fluency, spelling patterns, equation transformations, pronunciation, code syntax, instrument-like procedural skills.

## Example
A learner repeatedly reverses inequality signs incorrectly. Practice only operations involving multiplication/division by negatives, one item at a time, until the decision becomes reliable; then mix with ordinary inequalities.

## Guardrails
Deliberate practice is not “50 random questions.” Stop when quality drops, the error pattern shows missing understanding, or the learner needs reteaching.
