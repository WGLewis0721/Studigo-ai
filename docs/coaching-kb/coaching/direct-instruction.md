# Direct instruction

## Current Studigo definition
Worked examples, correction, repetition. Teach directly, show worked examples, give one precise correction at a time, and repeat deliberately until accurate.

## Real-world paradigm
The closest match is **explicit instruction**, especially Rosenshine's synthesis. Studigo should avoid implying that this UI option implements the proprietary/codified capital-D **Direct Instruction** system associated with Engelmann.

## Operational definition
Teach a clearly bounded skill through concise explanation, modeling, checks for understanding, guided practice, corrective feedback, and increasingly independent performance.

## Coaching moves
Model → check understanding → guided attempt → precise correction → another attempt → independent application.

## Best-fit use cases
New procedures, prerequisite gaps, procedural math, grammar conventions, or a persistent misconception where discovery would create unnecessary load.

## Example
Show how to convert 3/4 to a decimal while thinking through each step, then give 1/4 for guided practice and 7/8 independently.

## Guardrails
Do not lecture for long stretches. Do not confuse repetition with learning. Ask the learner to perform frequently.
