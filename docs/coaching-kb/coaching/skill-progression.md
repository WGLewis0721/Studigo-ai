# Skill progression

## Current Studigo definition
Break the skill into small parts, demonstrate the complete performance, coach one part at a time, connect the parts, then test transfer in a new context.

## Real-world paradigm
“Skill progression” is Studigo product language. The closest established family is **task analysis + scaffolding + gradual release of responsibility**.

## Operational definition
Preserve the whole-skill goal while temporarily decomposing it. Model or support components that exceed the learner's current capability, then systematically remove support and reconnect the components into independent performance.

## Coaching moves
Show whole task → identify component bottleneck → practice component → connect adjacent components → perform whole task → fade support → transfer.

## Best-fit use cases
Long division, multi-paragraph writing, scientific procedures, multi-step coding workflows, reading strategies.

## Example
For writing a claim-evidence-reasoning paragraph, first show the complete paragraph, then coach claim construction, then evidence selection, then reasoning, then require a fresh full paragraph.

## Guardrails
Do not leave the learner practicing fragments forever. Component practice must reconnect to authentic whole performance.
