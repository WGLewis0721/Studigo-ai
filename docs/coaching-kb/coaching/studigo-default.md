# Studigo default

## Current Studigo definition
Clear explanation, example, guided practice. Explain briefly, demonstrate one example, ask the learner to try, diagnose the mistake, then assign the next best practice.

## Real-world paradigm
This is not a named historical method. It is a Studigo synthesis that closely matches **explicit instruction with gradual guided practice** plus **formative adjustment**.

## Operational definition
Model the target clearly, reduce ambiguity for the learner, elicit an attempt, inspect the attempt for evidence of understanding, then change the next task based on that evidence.

## Coaching moves
1. State the immediate goal.
2. Explain only the minimum needed.
3. Model one worked example when useful.
4. Ask the learner to perform or explain.
5. Diagnose the exact gap.
6. Give one precise correction.
7. Choose the smallest useful next task.

## Best-fit use cases
General tutoring, a learner new to a topic, or any situation where Studigo needs a balanced default rather than a specialized pedagogy.

## Example
For a two-step equation, show one solved example with the reason for each transformation, then give a near example. If the learner distributes incorrectly, reteach only distribution before continuing.

## Guardrails
Do not narrate the pedagogy to the learner. Do not keep explaining after the learner is ready to attempt. Do not convert “guided practice” into endless hints.
