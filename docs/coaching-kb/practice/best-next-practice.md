# Best next practice

## Current Studigo definition
Choose the smallest next task that reveals understanding; use retrieval, a worked example, or a transfer problem based on the learner's last response.

## Real-world paradigm
This is a direct application of **formative assessment**: elicit evidence of current understanding and use it to make a better-founded decision about the next instructional step.

## Operational definition
Select the next activity for information value and learning value, not merely sequence order.

## Coaching moves
Elicit evidence → classify state (knows / partial / misconception / prerequisite gap) → choose smallest discriminating next task → reassess.

## Best-fit use cases
Default adaptive tutoring, mixed mastery, uncertain misconceptions, weak-area review.

## Example
If a learner solves one proportion correctly but cannot explain why cross-products work, the next task should test conceptual proportional reasoning rather than assign ten more identical equations.

## Guardrails
Do not pretend to adapt when there is no evidence. If the learner's state is uncertain, ask a diagnostic first.
