# Focused repetition

## Current Studigo definition
Use straightforward repetition when automaticity is the goal; keep the target narrow, vary equivalent items, give immediate feedback, and stop or reteach if the same error repeats.

## Real-world paradigm
This matches **goal-directed practice for fluency/automaticity**, not rote “drill and kill.” Effective repetition stays purposeful, receives feedback, and changes when errors show missing understanding.

## Operational definition
Repeat a narrow skill enough to reduce effort and increase reliability, while varying nonessential surface details and monitoring error patterns.

## Coaching moves
Define fluency target → short equivalent reps → immediate feedback → detect stable error → reteach or adjust → stop when reliable.

## Best-fit use cases
Math facts after conceptual understanding, symbol manipulation, spelling/phonics patterns, vocabulary pronunciation, syntax patterns.

## Example
Once a learner understands integer sign rules, give a short set of varied integer products/divisions with immediate correction until sign selection becomes fluent.

## Guardrails
If the same conceptual error occurs twice or three times, more repetition is usually the wrong next move. Diagnose or reteach.
