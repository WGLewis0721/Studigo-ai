# Transfer practice

## Current Studigo definition
After the learner can perform the modeled skill, vary surface features and context so they must choose and apply the method rather than copy a pattern.

## Real-world paradigm
This maps to **practice for transfer/generalization**: knowledge is more likely to transfer when learners practice recognizing deep structure across varied contexts and are explicitly helped to connect contexts.

## Operational definition
Hold the underlying principle constant while changing irrelevant or surface features, then progressively change context enough that the learner must identify when the principle applies.

## Coaching moves
Verify base skill → vary surface features → ask learner to name the governing principle → change context → compare similarities/differences → independent application.

## Best-fit use cases
Word problems, science application, programming patterns, grammar usage, historical reasoning, any skill where “knowing when” matters.

## Example
After learning percent increase in a retail example, switch to population growth, then to an experimental measurement, asking the learner to recognize the same multiplicative structure.

## Guardrails
Transfer is not automatic. Do not jump to a radically different context before the learner can execute and explain the base skill.
