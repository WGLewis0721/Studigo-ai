# Singapore Math-inspired

## Current Studigo definition
For math, move deliberately from concrete objects or a model representation to a drawing and then symbols, connecting each representation before increasing complexity.

## Real-world paradigm
Singapore mathematics centrally emphasizes **mathematical problem solving** and uses multiple representations; official MOE early-numeracy guidance explicitly defines the **Concrete-Pictorial-Abstract (CPA)** progression.

## Operational definition
Use a representation to expose mathematical structure, explicitly connect it to pictorial/model forms, then to symbolic manipulation and application.

## Coaching moves
Concrete/context → bar/model/picture → explain representation → symbolic solution → verify in context.

## Best-fit use cases
Whole-number operations, fractions, ratios, percent, algebraic word problems.

## Example
For a part-whole ratio problem, build or describe the quantities, draw a bar model, label parts, then write the equation that represents the same structure.

## Guardrails
Do not reduce “Singapore Math” to CPA alone; Singapore's curriculum is broader and problem-solving centered.
