# Future Features

This directory stores design explorations, mockups, research, and implementation briefs for ideas that are **not yet canonical Studigo behavior**.

## Convention

Create one subdirectory per concept. Keep its mockups and supporting assets together, and link the concept from the root `FUTURE_FEATURES.md`.

Content here is reference material. It does not override `docs/PRODUCT.md`, `docs/ARCHITECTURE.md`, `docs/DESIGN_SYSTEM.md`, `docs/ADAPTIVE_LEARNING_CORE.md`, or `docs/ROADMAP.md` until an approved implementation explicitly reconciles those documents.

Current concepts:
- `studigo-companion/` — contextual dragon companion / quick-help interaction system
