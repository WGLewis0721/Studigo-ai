# Phase 3 visual evidence runner

Run `node scripts/phase3-visual-qa.mjs` against a local development server (`NEXT_PUBLIC_STUDIGO_PHASE3_FOUNDATION_UI=1 pnpm --filter @studigo/web dev --hostname 127.0.0.1 -p 3000`). Override `PHASE3_VISUAL_BASE_URL`, `PHASE3_VISUAL_DIR` or `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` when needed. Chromium must be installed (`pnpm exec playwright install chromium`). The matching GitHub Actions workflow installs it and uploads the report even on failures.

The runner captures the **same-commit** synthetic Study Room in legacy and Phase 3 shells across Coach, Materials, Quiz, Flashcards, Practice test, Mastery, Weak areas, Plan and Cram at 320, 390, 820 and 1440 pixels. It produces 72 regular room images, 72 enlarged room images, Home/first-run and source-inspector images, and `report.json`, checks the selected shell, visible navigation, horizontal overflow, 200% CSS zoom overflow, reduced-motion media query and running CSS animations, plus Tab/Shift+Tab focus visibility and Enter activation of all five sections.

CSS zoom is an automated enlarged-layout check, not a browser text-only zoom claim. Keyboard assertions cover section navigation, not every interaction or full focus order. The fixture uses synthetic evidence, is restricted to development/flagged previews, and cannot establish authenticated learner acceptance, source ownership, real file access, grading, voice, screen-reader fidelity, high-contrast or native-device success. Review screenshots from the exact PR SHA before accepting visual fidelity. No credentials, learner screenshots, production data or secrets are captured.

Additional checks cover Settings initial focus, forward/reverse Tab containment and Escape focus return; visible Materials source-count navigation; synthetic Quiz selection/confidence versus explicit submission; and native Source Spotlight modal position, Escape/Close focus return. Guide/source and quiz responses are intercepted synthetic browser data and do not test API authorization or AI quality. Home and first-run specimens are captured at all four widths with overflow and 200% CSS zoom checks.

`PHASE3_VISUAL_INTERACTIONS_ONLY=1` runs controls and Home checks without repeating the room matrix. `PHASE3_VISUAL_FORCED_COLORS=active` checks Windows-style forced-colors presentation, including a visible confidence-selection outline. Home additionally checks half-width CSS viewport reflow to distinguish breakpoint behavior from CSS zoom. Reports record browser version and Git source-tree hashes before and after; a changed tree invalidates the evidence run. Keep the source tree frozen during final capture.
