# Offline advisory BKT baseline

Run `python -m unittest discover -s evals/ml -p test_*.py` and `python evals/ml/run.py --output evals/ml/results/synthetic.json`. Uses only Python's standard library. The CLI accepts synthetic fixtures only; it does not export or train on production learner data. Real child-data work requires a separately authorized privacy-controlled pipeline.

The four-parameter BKT implementation predicts before observing each outcome, then updates the known-skill posterior and learning transition. Parameters are chosen from a small interpretable grid using only training learners before a fixed UTC cutoff. Learners are deterministically separated; held-out learner history can warm up sequential predictions but cannot fit parameters. Scored held-out outcomes are after the cutoff. The [CMU worked knowledge-tracing example](https://www.cs.cmu.edu/~listen/BNT-SM/kt.html) documents the underlying inference boundary.

Compare BKT against a five-attempt recent-performance predictor and a supplied **pre-outcome** canonical-state comparator. The latter requires a probability mapping/version recorded by a future authorized exporter; it is not a mastery percentage or a calibrated probability by default. `canonicalAt` must precede the answer. The synthetic example's constant comparator tests plumbing only. Fit/report Brier score, log loss, expected calibration error and calibration bins; report grade-band and subject subgroup metrics with their sample sizes. Empty samples yield unavailable metrics, never a passing result.

Input has pseudonymous IDs, concept/encounter IDs, timestamps, grade band, subject, boolean independent correctness, assistance/evidence type and the pre-outcome comparator. It rejects extra fields such as learner names and answer text. Only assessed, unassisted outcomes are eligible; retries deduplicate and only the first target per encounter is used. A separately reviewed source/provenance export remains required for actual learner evidence.

Output is advisory only. This module has no database connection, provider credentials, policy writer, mastery updater or difficulty authority. Synthetic measurements validate the harness, not learning effectiveness or subgroup fairness. DKT/reinforcement learning remain deferred.
