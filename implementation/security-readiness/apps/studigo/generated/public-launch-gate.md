## Open release blockers

### GMS-API-002: Rate, concurrency and cost limits

- Severity **P0**, status **fail**, risk 25, owner role Engineering, effort L
- Finding: No centralized public rate/concurrency/spend guardrail was found for model, OCR, embedding and other expensive operations.
- Action: Implement per-user/IP rate limits, concurrent-operation caps, token/work budgets, daily spend ceilings and a global provider circuit breaker.
- Done when: Expensive routes have per-user and per-IP rate limits enforced at the edge and in the app. Model calls set output-token caps and timeouts; retries are bounded. Per-user daily budgets and a global spend ceiling/circuit breaker exist. Reprocessing/regeneration paths cannot loop without limit.
- Evidence: apps/web/app/api/chat/route.ts, apps/web/app/api/documents/process/route.ts

### GMS-ACCESS-003: Auxiliary/internal services authenticated

- Severity **P0**, status **fail**, risk 20, owner role Engineering, effort M
- Finding: Optional Python retrieval service exposes index/search/flashcards/delete operations using supplied room IDs without an authenticated Studigo principal.
- Action: Keep service loopback/private-only or add service authentication plus caller/room authorization and network restrictions before any public deployment.
- Done when: Every auxiliary service either listens only on a private/loopback network or authenticates callers. Auxiliary services authorize the tenant/owner of every request, not just the caller service.
- Evidence: services/retrieval/app/main.py, services/retrieval/README.md, apps/web/lib/retrieval-client.ts

### GMS-FILE-002: Content signature and parser validation

- Severity **P0**, status **partial**, risk 20, owner role Engineering, effort S
- Finding: assertContentMatchesType checks bytes for every allowed format (PDF header, PNG/JPEG/WEBP signatures, OOXML ZIP with the expected main part, UTF-8 text without NUL) before storage. Polyglot detection (e.g. PDF+HTML) is not implemented.
- Action: Add polyglot rejection, or re-serve originals only with a forced download Content-Disposition and nosniff.
- Done when: The bytes of every upload are checked against the accepted type (magic bytes / structure). A renamed or polyglot file is rejected before storage or parsing.
- Evidence: packages/documents/src/index.ts, packages/documents/src/file-safety.ts, apps/web/app/api/documents/upload/route.ts

### GMS-FILE-003: Archive/decompression/image/OCR resource bounds

- Severity **P0**, status **partial**, risk 20, owner role Engineering, effort M
- Finding: OCR page and chunk limits exist. assertSafeZip now rejects OOXML archives over 5000 parts, 300 MB declared expansion or 100x ratio, at upload and before extraction. Central-directory sizes can be understated by a crafted archive; image pixel/dimension limits, PDF object-stream bombs and parser time/memory budgets are still missing.
- Action: Add pre-extraction archive expansion/file-count limits, image dimension limits, parser time/work limits and bomb fixtures.
- Done when: Archive-based formats are bounded by entry count, expanded size and ratio before inflation. Image dimensions, page counts and OCR pages are capped. Parsers run with time and memory budgets.
- Evidence: apps/web/lib/validation.ts, packages/documents/src/extract.ts, packages/documents/src/file-safety.ts

### GMS-ACCESS-001: Object-level authorization / tenant isolation
