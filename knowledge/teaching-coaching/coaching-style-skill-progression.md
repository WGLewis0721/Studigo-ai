# Skill Progression → Scaffolding / Gradual Release

## Current Studigo definition

**Description:** Small parts, connected phrases, performance.

**Instruction:** "Break the skill into small parts, demonstrate the complete performance, coach one part at a time, connect the parts, then test transfer in a new context. Correct, repeat, and increase challenge only after evidence of mastery."

## Real-world alignment

"Skill progression" is a Studigo label, not a canonical research tradition.

The definition is best understood as a composite of:

- **scaffolding**: temporary support for a task the learner cannot yet complete independently;
- **gradual release of responsibility**: movement from modeling/guidance toward independent performance;
- **part-to-whole practice**: isolate meaningful components, then reintegrate them into the whole performance.

## Definition

The coach preserves a clear whole-task goal, identifies the component that blocks performance, supports that component, reconnects it to the full skill, and fades help as competence appears.

## Core sequence

1. Demonstrate or define the complete performance.
2. Diagnose which component is blocking success.
3. Reduce complexity or support that component.
4. Let the learner perform the supported part.
5. Reconnect the part to the whole task.
6. Fade one support.
7. Require independent performance.
8. Change context to test transfer.

## Best-fit use cases

- Writing a paragraph or essay.
- Multi-step math procedures.
- Reading-comprehension routines.
- Lab or technical procedures.
- Any task where the learner can perform some components but not the full sequence.

## Cautions

- A scaffold that never fades creates dependence.
- Do not atomize a task until the parts lose their relationship.
- Support should respond to learner performance, not a fixed stage count.
- If a prerequisite is absent, explicit instruction may be more efficient.

## Example

**Paragraph writing:** Studigo models claim–evidence–explanation, then provides a paragraph frame, then only a checklist, then a new prompt with no scaffold. The final task changes context to verify transfer.

## Recommended coaching rules

- Start from the complete skill so the learner knows the goal.
- Support the smallest blocking component.
- Fade support after success.
- Restore support temporarily if performance collapses.
- Require transfer before calling the skill independent.
