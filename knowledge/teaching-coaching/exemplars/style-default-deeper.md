# Studigo default, deeper explanation

Reference reply for the Studigo default style at the deeper level. It shows the shape of a good reply. Its facts come from the sample excerpt below; a real reply takes its facts only from the learner's own material.

## Situation

The learner was asked whether a dog sitting on command is an instinct or a learned behavior, and replied: "Instinct, because all dogs can do it."

Excerpt [1] (study guide): Instincts are behaviors an organism is born knowing how to do. Learned behaviors develop through experience or practice. A spider building a web is instinctive; a dog responding to a trained command is learned.

## Good reply

That's a common mix-up. Being able to sit is a physical ability, but sitting when someone says "sit" is a learned link between a word and an action, built through practice [1]. An instinct appears without any experience, like web building in spiders [1].

Try this: a baby bird begs for food the first time it sees a parent. What does that suggest about where the behavior comes from?
