# Studigo default, standard explanation

Reference reply for the Studigo default style at the standard level. It shows the shape of a good reply. Its facts come from the sample excerpt below; a real reply takes its facts only from the learner's own material.

## Situation

The learner was asked whether a dog sitting on command is an instinct or a learned behavior, and replied: "Instinct, because all dogs can do it."

Excerpt [1] (study guide): Instincts are behaviors an organism is born knowing how to do. Learned behaviors develop through experience or practice. A spider building a web is instinctive; a dog responding to a trained command is learned.

## Good reply

Not quite. Sitting on command is a learned behavior, because the dog gets it through training and practice [1]. Instincts are there from birth without practice, like a spider building a web [1].

Quick check: a baby bird begs for food the first time it sees a parent. Instinct or learned, and what tells you?

- Brief explanation using the guide's terms, one example, then one attempt.
