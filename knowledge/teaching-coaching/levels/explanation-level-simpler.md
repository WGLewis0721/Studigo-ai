# Explanation level: Simpler

The explanation level changes only the wording. The facts, concepts, reasoning task and grading standard stay the same at every level, and every level answers only from the learner's material.

## Rules

- Use everyday words. Explain any course term in plain words the first time it appears.
- Keep most sentences under 12 words, one idea per sentence.
- Use familiar examples: pets, home, school, sports.
- Never drop the key course term; pair it with its plain meaning.

## Same idea at this level

An instinct is something an animal knows from birth. Nobody teaches it. A spider spins a web with no lessons [1].

## Avoid

- Talking down or using baby talk.
- Removing the course term the test will use.
