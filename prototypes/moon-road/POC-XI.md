# POC XI — Moon Library (toolchain proof)

A sibling of the golden POC X (`dist/poc-x/` is untouched). `dist/poc-xi/` is POC X plus one new room, **T Moon Library**, used to prove the LDtk → TexturePacker → Phaser pipeline from [TOOLCHAIN.md](TOOLCHAIN.md).

- Route: `dist/poc-xi/`. Not linked from the Studigo app.
- Entry: east door of the Trine Guardian room (map 8,1), behind a `3 · 4` seal (×3 or ×4 beam). Beat the Trine Guardian first.
- Contents: a save shrine (×2/×3 refills), skeleton `2 · 3`, skeleton `4 · 1`, bat `1 · 4`, and a `12` stone block (×2, ×3 or ×4) over **energy tank 5** (+1 max heart). Map is now 19 rooms, 10 collectibles.

## How the room is made

| Step | Source | Output |
| --- | --- | --- |
| Layout and entities | `art-source/poc-xi/moon-library.ldtk` (edit in LDtk) | |
| Export | `node scripts/ldtk-export.mjs` | `dist/poc-xi/levels.js` (generated; a test fails if it drifts from the .ldtk) |
| Props (shelf, lantern, lectern, books) | `scripts/make-library-props.py` -> `art-source/poc-xi/frames/*.png` (polish in Pixelorama) | |
| Atlas | `node scripts/pack-library-atlas.mjs` (TexturePacker, Phaser format) | `dist/poc-xi/art/library.png/.json` |

LDtk conventions: IntGrid `Collision` 1 = wall, 2 = one-way platform. Skeleton/Item/Shrine sit in the open cell above the floor; Bat sits where it hangs; Block size is its footprint; Prop anchor is bottom-left in pixels.

## Status and caveats

- Tests: `node --test "test/**/*.test.mjs"` (113 pass, includes world graph, solver and .ldtk/levels.js sync).
- Rendered and checked in the browser; not yet playtested end to end by hand.
- The `.ldtk` was generated by script, not first authored in LDtk. LDtk opens it, but re-saving in LDtk may reformat the JSON (the export still works).
- TexturePacker is a licensed local tool; only its output atlas is committed.
